# Work in progress: Kerbal Konstructs

Part of [Terrain Precision Fix](../../README.md), one mod of [Work in progress](../work-in-progress.md): what is still to check, on Kerbal Konstructs.

Its statics carry the same defect as the KSC's, and this mod corrects them: measured on a runway it
placed on the Mun, in [Checking the statics: loading the same save](../checking-the-culprit-loading/the-statics.md).
Its group editor needs a patch of this mod: [Limits and solutions](../limits-and-solutions/kerbal-konstructs.md).

above the deck is still active under the craft; not a rounding, and this mod does not touch it.
